# @shukka/sdk

TypeScript client for the [Shukka](https://github.com/shukka-app/shukka) release API.

```bash
npm install @shukka/sdk
```

```ts
import { createShukkaClient } from '@shukka/sdk'

const shukka = createShukkaClient({
  baseUrl: 'https://updates.example.com',
  apiKey: 'shk_…',
})

const { data } = await shukka.getApp({ path: { appSlug: 'demo' } })

await shukka.setCurrentVersion({
  path: { appSlug: 'demo', channel: 'stable' },
  body: { currentVersion: '1.4.0' },
})

// Public feed and notes need no key.
const feed = createShukkaClient({ baseUrl: 'https://updates.example.com' })
const notes = await feed.listPublicNotes({ path: { appSlug: 'demo', channel: 'stable' } })
```

`src/client/` is generated by `@hey-api/openapi-ts` from `../../spec/openapi.json` — do not
edit it. `src/index.ts` binds one configured client into the generated operations; adding an
operation means adding one line there.

Errors are returned as `{ data, error, response }`; pass `throwOnError: true` to throw instead.

Build: `pnpm build` (tsup → ESM + CJS + d.ts).
